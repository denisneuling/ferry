# Mockup

The approved look of ferry's interface, direction "Hafen" (2026-11-21): a
static, clickable page with no backend. Open `index.html` in a browser.

- Log in with any name; the password `wrong` shows the failed login.
- Shares, a folder as a list or a grid, the preview with its filmstrip, the
  transfers panel, a phone layout, English and German.
- `shared/data.js` holds the fictional sample data (the user `alex` on
  `nas.example.lan`), `shared/i18n.js` the texts, `shared/app.js` the
  behaviour.

It is a design reference, not code the interface reuses. Unlike the product,
the mockup loads its fonts from Google Fonts; ferry serves Fraunces and DM
Sans itself and loads nothing from a third-party origin.
